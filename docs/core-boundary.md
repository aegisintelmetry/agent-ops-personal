# 제품 코어와 운영 하네스 경계

AEGIS Agent Ops는 서비스 연동 플랫폼의 클라이언트이며 운영 하네스의 새 배포본이 아닙니다.

## 제품 소유

- Electron 앱, 에이전트별 모델·키 설정, OS 보안 저장소, 개인용 대화.
- `agent_ops/desktop`: 로컬 브리지, 설정 확인, 명시적으로 승인한 조직 설치 및 실행기 수명 관리.
- `agent_ops/client`: 인증과 프로필 저장, 등록된 러너 메타데이터 읽기, 하트비트·번들 조회.
- 기존 HTTPS API를 이용한 호스트 등록과 설치 진행 보고. 서버 권한 검증은 서버가 담당.
- 기존 로컬 halt 기록은 읽기만 수행. halt 발행/해제나 거버넌스 기록 작성 기능 없음.

## 운영 하네스 소유

- 미션 무결성, 작업 생성·선점·리스·상태 변경, watchdog·복구·QA 디스패치.
- 중앙 서버 운영 정책과 프로파일 프로비저닝.
- 운영 번들의 발행, 전체 PC 배포 및 실제 supervisor/worker 구현.

제품은 승인된 외부 운영 번들을 해시 검증 후 설치할 수 있습니다. 그 번들 내부의
`harness/runners`, `harness/runtime`과 supervisor 경로는 기존 외부 데이터/설치 계약입니다.
이 경로 이름을 바꾸는 것은 운영 서버·번들의 별도 호환성 변경이며 이번 제품 분리에서는 하지 않습니다.
`BTK_*` 환경 변수, IPC, 실행 파일명 역시 기존 프로필 호환 계약으로 유지합니다.

## 자동 검증

- 제품 Python 소스의 `harness` import 금지 검사.
- PyInstaller에서 `harness` 제외 및 수집 모듈 검사.
- 읽기 전용 MCP 연산 허용 목록: `runner.heartbeat.list`, `artifact.list`, `artifact.download`.
- 작업 생성/선점/상태 변경/업로드 요청은 네트워크 호출 전에 거부.
- 등록 서버 주소와 러너 신원은 명시적 설정 필수. 운영 서버 IP나 PC 신원 기본값 없음.
- 기존 조직 등록 API 경로·토큰 범위와 개인용 동작의 회귀 시험.

Git 이력에는 최초 가져오기 원본이 보존됩니다. 현재 트리에서 하네스가 제거됐다는 사실이
과거 커밋에서도 삭제됐다는 뜻은 아닙니다. 공개 권한·라이선스 검토는 이력까지 포함해야 합니다.
