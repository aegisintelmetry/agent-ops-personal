# AEGIS Agent Ops 0.5.16

## What's Changed

- Add Sources and Output controls to the Personal conversation workspace.
- Read text from TXT, Markdown, CSV, JSON, PDF and Word DOCX attachments.
- Review Markdown documents with preview/source modes, copy content, save TXT/MD
  files through a native Save As dialog, and prepare follow-up revision requests.
- Restore conversations, drafts, attachments and document responses after restart
  using OS-encrypted local storage. Interrupted requests remain failed/cancelled.
- Keep each agent's conversations separate and retain the original response model.
- Preserve existing conversations when changing model settings.
- Add local PNG/JPEG/WebP previews and Korean/English responsive workspace panels.
- Bound document parsing and conversation context; keep existing transmission
  protections, renderer isolation and explicit file-save boundaries enabled.

## Upgrade

On **0.5.15**, open **App updates**, check for updates, download **0.5.16**, then
approve **Restart and install**. Copy important conversations before upgrading
from 0.5.15: that version does not persist chat history, and this release cannot
recover history lost when the older app closes.

Versions **0.5.14 and earlier** must install `AEGIS-Agent-Ops-Setup-0.5.16.exe`
manually. Model settings use the existing app profile; no new account is required.

The installer, `.blockmap` and `latest.yml` are published together. Download
checksums verify file integrity, not publisher identity. **Windows builds remain
unsigned**, and Windows may display a security warning. No certificate or signed
publisher status is claimed.

## Scope and Limits

- At most five source files and 12,000 extracted characters per conversation.
- Text files: 48 KB each. PDF/DOCX: 2 MiB each; PDF: at most 100 pages.
- PDF/DOCX import extracts text, not original page layout or embedded images.
- Image attachments are **local previews only**, not model image understanding.
  Remove them before sending a text-only request.
- OCR, scanned/encrypted PDF import, image generation, XLSX/PPTX processing,
  native Office output, and cross-device history sync are not included.
- No additional Enterprise governance features are introduced by this release.

## Verification

Local verification covers Node/Python tests, responsive native Electron screens,
packaged document parsing, native copy/export, encrypted restart recovery and
model/session isolation. Provider responses use loopback fixtures; these checks
do not claim live provider inference, a fresh-PC installation, or a completed
real-world automatic upgrade on every supported Windows environment.
