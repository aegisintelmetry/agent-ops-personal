# 공개 체크리스트

## 0.5.10 공개 기록

- 공개 대상은 `aegisintelmetry/agent-ops-public-preview`의 선별 제품 이력입니다.
- 원본 전체 이력 및 운영 하네스 저장소는 비공개로 유지합니다.
- 초기 하네스 커밋은 이 저장소에 존재하지 않음을 GitHub API로 확인했습니다.
- 선별 11개 커밋 비밀값 검사 탐지 0건, Windows CI 35728422763 성공을 확인했습니다.
- 보안 메일 수신 가능 여부는 운영자가 확인했습니다.
- 운영자는 Security FDE와 별개인 오픈소스 Personal 프로젝트로 공개를 승인했습니다.
- 실제 Google 인증/추론 및 새 PC 설치는 미검증이며, 바이너리는 미서명 프리뷰입니다.
- 아래 항목은 향후 정식 배포에도 적용하는 유지보수 체크리스트입니다.

## 코드 및 재현

- 조직 모드 미선택/개인용/설정 손상 시 모든 조직 IPC 차단 회귀 시험.
- 신규 프로필의 운영 러너 신원이 비어 있는지 확인.
- Node/Python 테스트, Vite 빌드, 네이티브 창 크기 및 에이전트 격리 시험.
- Git 이력 비밀값 검사, npm audit, Python 및 배포 의존성 검토.
- `source-import.json`은 최초 가져오기 증거이며 최신 소스 검증값이 아님.
- 내부 BTK 프로토콜 이름과 등록된 조직의 레거시 러너 매핑은 호환용이며 공용 기본값이 아님.

## 운영자 확인 항목

- 기존 코드의 공개 권한, 제작사 명의 확정.
- AEGIS 이름의 사용 권리와 새 GitHub 소유 계정/조직 확정.
- 보안 신고 주소 `contact@aegistelemetry.com`의 실제 수신 확인. 최신 0.5.x 프리뷰 지원 범위는 SECURITY.md 참조.
- 실제 배포 의존성의 라이선스/고지 포함 여부 검토.

법적 명의나 공개 권한은 빌드 스크립트가 추정하지 않습니다.
저작권자는 운영자 확인에 따라 `aegisintelmetry`로 설정했습니다.
라이선스는 운영자의 Apache-2.0 추천 진행 승인에 따라 `Apache-2.0`으로 설정했습니다.
`LICENSE`는 공식 원문이며 `NOTICE`에 저작권자와 초기 출처를 기록했습니다.
설치 패키지의 `resources/LICENSE`, `resources/NOTICE`에도 함께 배포하며 제3자 고지를 유지합니다.
이 결정은 기존 코드 공개 권한이나 과거 Git 이력 처리에 대한 답변을 대신하지 않습니다.
프리뷰의 `author.name`은 제작사 명의 결정 전까지 비웁니다.
서명 인증서의 발행자 명의와 라이선스 고지는 별도로 확인합니다.
기존 출처와 저작권 고지를 임의로 지우지 마세요.

공개용 선별 개발 이력은 [공개 이력 방침](public-history.md)을 따릅니다.
원본 저장소는 비공개로 보관하며 과거 태그를 공개 후보로 복사하지 않습니다.

## Windows 배포

```powershell
powershell -NoProfile -File apps/desktop/build-windows.ps1
```

기본 빌드는 미서명 로컬 프리뷰입니다. 설치본 서명은 제공된 인증서와 적법한
발행자 명의가 필요하며 이 저장소에는 인증서를 저장하지 않습니다.
Electron Builder의 서명 설정을 갖춘 별도 릴리스 작업에서 서명을 수행하고
프리뷰의 `win.signExecutable: false`를 서명 활성화 설정으로 덮어써야 합니다.
정식 서명 배포는 `Get-AuthenticodeSignature`가 `Valid`인지 확인해야 합니다.
현재 프리뷰는 미서명임을 명시하여 배포하며 이를 정식 서명 배포로 표시하지 않습니다.
로컬 코어 메타데이터의 `signed: false`를 근거 없이 변경하지 마세요.

새 PC에서 설치/제거, 재시작, OS 키 암호화, 실제 로그인, 공급자별 요청과 계정 격리를
확인해야 합니다. 개발 PC의 임시 프로필 시험은 이 검증을 대체하지 않습니다.
실제 호출은 비용/구독 한도를 소비할 수 있습니다.

제품명은 AEGIS Agent Ops이고 내부 패키지 이름과 저장 구조는 호환성을 위해 유지됩니다.
기존 BTK 프리뷰와 앱 ID가 달라 별도 설치가 됩니다. 자동 프로필 이전이나 구버전 제거는 하지 않습니다.
