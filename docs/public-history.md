# 공개용 개발 이력

공개 후보는 기존 비공개 저장소의 전체 복제본이 아닙니다.
운영 하네스를 제거하고 Apache-2.0 고지를 적용한 0.5.4 제품 스냅샷을 기준으로
독립적인 최초 커밋을 만들고, 이후 제품 개선 커밋만 순서대로 이식합니다.
원래 개발자 정보와 변경 설명을 보존하며 최초 스냅샷의 날짜를 과거로 꾸미지 않습니다.

공개 제외 범위는 운영 하네스 코드, 중앙 서버 구현, 고객/러너 설정과 인증 정보입니다.
이식 전 초기 운영 코드가 포함된 커밋과 기존 릴리스 태그는 공개 후보에 가져오지 않습니다.
기존 전체 이력과 릴리스는 원본 비공개 저장소에 보관합니다.

## 공개 점검

- 후보의 모든 커밋과 태그에서 제외 코드 및 비밀값을 재검사합니다.
- 현재 제품 소스와 후보의 최종 트리가 일치하는지 확인합니다.
- Windows CI를 후보 저장소에서도 통과시킵니다.
- 공개 직전 보안 신고 메일의 실제 수신을 운영자가 확인합니다.
- 실제 공급자 인증과 새 PC 설치 미검증, 미서명 바이너리 상태를 명시합니다.

이 문서는 이력 선별 방침이며 원본 저장소의 Public 전환을 승인하지 않습니다.
